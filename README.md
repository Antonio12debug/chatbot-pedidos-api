📌 Visão Geral
Projeto desenvolvido para simular uma plataforma de inteligência conversacional utilizando Python.

A aplicação permite consultar, criar, atualizar e remover pedidos utilizando linguagem natural através de uma interface web desenvolvida com Streamlit.

🎯 Objetivo
Simular uma solução de Inteligência Conversacional capaz de transformar mensagens em operações de negócio através de APIs REST.

O projeto foi inspirado em conceitos utilizados por plataformas conversacionais corporativas como a Blip.
